01 — Hypotheses

Three signals.
Testable. Falsifiable.

H1 — FREQUENCY
Session frequency drop precedes churn
Rolling 7/14-day session counts begin declining 7–14 days before a user goes fully inactive. The slope of decline, not just the level, is the critical signal.
Mann–Whitney U · t-test
H2 — INTER-EVENT TIME
Widening gaps between sessions is a leading indicator
The trend in inter-session gaps (not just average gap) predicts churn. A user whose gaps are widening session-over-session is at risk even before total frequency drops.
KS-test · Distribution shift
H3 — VOLATILITY
Engagement volatility outperforms average activity
Coefficient of variation in session frequency predicts churn better than raw averages. Normalising against a user's personal baseline eliminates power-user vs casual-user noise.
Logistic regression · OddsRatio
02 — Feature Engineering

Six signal families.
One feature matrix.

RF
Recency & frequency
Rolling 7/14-day session counts, active days, days since last activity. Fastest-moving signals — typically the top predictors in any model.
TR
Activity trend & acceleration
OLS slope on daily sessions. Acceleration = slope of second half minus first half of window. Accelerating decline is far higher risk than steady slow decline.
VL
Volatility (CV)
Coefficient of variation guards against false positives. A high-CV user going quiet once is not the same as a stable user going dark.
IE
Inter-event time
Average gap, max gap, and slope of gap sequence. Widening gaps are a pre-churn signal that appears before overall frequency drops.
BL
Personal baseline comparison
% change vs user's own 30-day baseline. Normalises power users vs casual users. 35%+ drop flags ~3× churn hazard directly.
ED
Engagement depth
Actions/session, features used/session. Shallow engagement precedes frequency drop by 3–5 days — the earliest leading signal in the system.

03 — Statistical Methods

Each method chosen
for a specific reason.

01
MANN–WHITNEY U · T-TEST
Validate the frequency drop hypothesis
Activity data is right-skewed and zero-inflated — never normally distributed. Mann–Whitney tests whether churners had systematically lower activity without assuming normality. Run at 3d, 7d, and 14d lookbacks to find where the signal is strongest.
Output
p-value per lookback window
Effect size (rank-biserial r)
Optimal window identification
02
KOLMOGOROV–SMIRNOV TEST
Detect inter-event gap distributional shifts
KS test compares the full distribution of inter-session gaps between churners and non-churners. Mean alone would miss bimodal patterns — churners often show a mix of short gaps followed by one very long gap before going dark.
Output
KS statistic + p-value
Distributional shift visualisation
Critical gap threshold
03
KAPLAN–MEIER · COX PH MODEL
Model time-to-churn, not just churn probability
KM curves show exactly when each cohort is most at risk — the steepest part of the curve is your intervention window. Cox model extends this with hazard ratios: "35% activity drop = 3× instantaneous churn hazard." Schoenfeld residuals test proportionality.
Output
Survival curves per cohort
Hazard ratios per feature
Critical window timing
04
LOGISTIC REGRESSION · XGBOOST
Predict individual churn probability
Logistic regression first — if features are good, it'll work. If it doesn't, the features are wrong, not the model. XGBoost as main model with time-based validation (train on months 1–6, validate on 7, test on 8). PR-AUC prioritised over ROC-AUC due to class imbalance.
Output
Per-user churn probability
Risk tier assignment
PR-AUC / Recall @ threshold
